# Kit sample knowledge base

These documents describe **Kookaburra Coffee Co.**, a fictional Sydney
coffee roaster invented for this starter kit. Every name, price, and policy
here is made up — the point is to give Kit's retrieval a small, concrete
corpus so you can watch RAG work the moment you deploy.

Try asking the agent:

- "How much is a bag of the Marrickville Morning blend?"
- "What's Kookaburra Coffee's return policy on equipment?"
- "Do they ship to Perth, and how long does it take?"

The answers only exist in these files, so a correct reply proves the
knowledge base is wired up.

**To use your own data:** replace the files in this folder with your own
documents and redeploy — the extension guide covers formats, chunking, and
larger corpora.
